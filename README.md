This readme is for the pset1 repo for this class that helps us learn how to use github and commit, push, and pull changes
The `cars` dataset is a built-in R dataset containing vehicle speed and stopping distance measurements. 
The `summary(cars)` command provides basic descriptive statistics for both variables, such as the minimum, median, mean, and maximum. The scatterplot shows the relationship between speed and stopping distance, with faster cars generally requiring longer distances to stop.
